## 🐛 نکات مهم (باگ‌ها و راه‌حل‌ها)

### ⚠️ `useSearchParams` بدون `Suspense`
- خطا: صفحه سفید
- راه‌حل: با `<Suspense>` wrap کن

### ⚠️ `FadeIn` دور `CourseCard`
- خطا: صفحه سفید
- راه‌حل: `CourseCard` رو بدون `FadeIn` بذار

### ⚠️ PowerShell Execution Policy
- خطا: `npm run dev` کار نمی‌کنه
- راه‌حل: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

### ⚠️ Windows CMD vs Linux
- `rm -rf` → `rmdir /s /q`
- `ls` → `dir`
